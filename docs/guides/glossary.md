# 용어집

내부 모델명과 화면에 보이는 문구가 다른 경우를 구분

## 개념 계층

```
작업(Task) ··선택 연결··▶ 세션(Session) ──구성──▶ 사이클(Cycle) ──구성──▶ 페이즈(Phase)
 무엇을 할지                타이머 한 번의 실행 기록     집중과 휴식 한 쌍          집중 또는 휴식
```

| 개념 | 정의 | 코드 |
|---|---|---|
| 작업 Task | 앞으로 할 일, 제목과 카테고리만 가짐 | `Task` |
| 세션 Session | 타이머를 한 번 실행한 기록, 작업 연결은 선택 | `Session` |
| 미분류 | 작업 없이 시작했거나 작업이 삭제된 세션 | `taskId === null` |
| 사이클 Cycle | 집중과 휴식 한 쌍, `totalCycles`번 끝나면 세션 종료 | 별도 타입 없음 |
| 페이즈 Phase | 사이클을 이루는 두 상태 | `TimerPhase` — `focus`, `short-break` |
| 모드 | 사이클이 있는 포모도로와 시간만 재는 자유 모드 | `TimerMode` — `pomodoro`, `free` |
| 타이머 기본값 | 설정에서 정한 집중, 휴식, 사이클 값, 시작 화면의 초기값 | `AppSettings.defaultTimerSettings` |
| 집중 구간 | 일시정지 없이 실제로 집중한 시간 블록, 타임라인 표시용 | `FocusPeriod[]` |
| 저널 | 지난 세션을 목록과 캘린더로 보고 인사이트를 확인하는 화면 | `components/journal/` |
| 대시보드 | 세션을 집계한 차트, 스트릭, 뱃지 화면 | `components/dashboard/` |

## 화면 문구 규칙

화면에는 세션이라는 말을 쓰지 않고 문맥에 따라 타이머와 기록으로 나눠 씀

| 문맥 | 화면 문구 | 예시 |
|---|---|---|
| 진행 중 — 시작, 설정, 종료하는 시점 | 타이머 | 타이머 시작, 타이머를 종료할까요?, 이번 타이머 설정 |
| 완료 후 — 저장된 데이터 | 기록 | N개의 기록, 기록 상세, 아직 기록이 없어요 |

| 내부 이름 | 화면 이름 |
|---|---|
| 대시보드 | 통계 |
| 저널 | 기록 |

- 사이클, 집중, 휴식은 그대로 씀
- 코드 식별자는 바꾸지 않음 — `Session` 타입, `sessions` 테이블, `SessionRecordModal` 등은 검색과 정확성을 위해 Session 유지
