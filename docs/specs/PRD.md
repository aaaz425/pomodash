# PRD — Product Requirements Document

> **제품:** Pomodash · **버전:** 1.2 · **현재 상태:** MVP + Phase 7(Supabase) + Phase 8(네이티브 앱) 완료

---

## 1. Executive Summary

Pomodash는 포모도로 기법 기반 학습 집중 도구다. 작업 계획 → 집중 타이머 → 기록 → 대시보드의 흐름을 웹과 네이티브 앱에서 동일하게 제공한다. 쌓인 집중 기록이 "오늘도 해냈다"는 성취감으로 이어지게 설계했다.

---

## 2. 배경 및 문제 정의

### 문제

SNS 알림, 추천 영상, 끊임없는 메시지가 주의를 빼앗는 환경에서도 수험생·취준생·직장인은 집중해서 해야 할 일을 해내야 한다.

기존 포모도로 앱의 한계: 기록이 안 보여 동기부여가 부족하고, 타이머만 있고 작업 관리가 없으며, 강제 전환 방식이 자율성을 저해한다.

### 해결

**"해야 할 일이 있는 사람"이 실제로 그 일을 해내도록 돕는다.**

- 작업 계획 → 집중 → 기록 흐름을 한 앱에서
- 타이머는 도구, 주도권은 사용자에게 (강제 전환 없음)
- 누적 대시보드로 성취감 제공

## 3. 타겟 사용자

| 유저 그룹 | 핵심 니즈 |
|-----------|-----------|
| 수험생 (수능, 공무원, 자격증) | 과목별 공부 시간 추적, 스트릭 유지 |
| 취업 준비생 | 자기소개서, 포트폴리오 작업 시간 기록 |
| 자기계발 직장인 | 퇴근 후 사이드 프로젝트/운동 집중 |
| 집중이 어려운 사람 | 짧은 집중 사이클로 시작, 성취감 경험 |

---

## 4. 목표 및 성공 지표

| 목표 | 지표 | 기준 |
|------|------|------|
| 즉시 사용 가능 | 첫 타이머 시작까지 클릭 수 | 3회 이내 |
| 재방문 유도 | 7일 리텐션 | 40% 이상 |
| 집중 기록 완성 | 기록 메모 작성률 | 30% 이상 |
| 성능 | Vercel Web Vitals LCP | 2.5초 이하 |
| 기기 간 동기화 전환 | 로그인 유저 전환율 | 30% 이상 |

## 5. 기능 범위

### In-Scope (완료)

| 기능 | 플랫폼 |
|------|--------|
| 포모도로 타이머 (집중/휴식 사이클, 절대시간 기반) + 자유 스톱워치 모드 | 웹 · 앱 |
| 집중 모드 (오버레이 + 동기부여 메시지) | 웹 · 앱 |
| 작업 CRUD + 카테고리 + 드래그앤드롭 | 웹 · 앱 |
| 집중 기록 + 회고 메모 + 집중도/방해요소 캡처 + 저널 인사이트 + 캘린더뷰 | 웹 · 앱 |
| 대시보드 (일/주/월 차트, 스트릭, 뱃지 수집, 공유 카드) | 웹 · 앱 |
| 설정 (타이머 기본값, 알림, 카테고리) | 웹 · 앱 |
| 로그인 (이메일 + 카카오) + Supabase 기반 기기 간 동기화 | 웹 · 앱 |
| PWA + Vercel 배포/Analytics, 랜딩 페이지 | 웹 |
| EAS 빌드 (iOS/Android 네이티브 앱) | 앱 |

### Out-of-Scope (백로그)

| 기능 | 비고 |
|------|------|
| 서브태스크 (작업 내 체크리스트) | 미정 |
| Claude AI 연동 (기록 분석, 조언) | 미정 |
| 멀티기기 동시 타이머 충돌 방지 | 서버 잠금 없음 — 현재 사후 경고 수준도 보류 결정, 메모리 참고 |
| 집중 방해 앱 차단 | OS 수준 권한 필요, 미정 |
| 정원 성장 시각화 | 드롭 — 뱃지 수집으로 대체 |

## 6. 사용자 여정

```
첫 사용자: 랜딩 방문 → 회원가입/로그인 → 작업 생성 → 타이머 시작
          → 집중 모드(선택) → 사이클 완료 → 타이머 종료 → 메모 작성
          → 대시보드에서 오늘 집중 시간 확인

재방문:   로그인 유지 상태로 메인 진입 → 기존 작업 선택 → 타이머 시작
          → 다른 페이지 이동 중 미니 타이머 확인 → 대시보드에서 스트릭 확인
```

## 7. 기술 제약 및 가정

- **동기화:** Supabase로 기기 간 데이터 동기화. 단, 두 기기에서 동시에 타이머를 실행하면 세션이 중복 저장될 수 있음(서버 잠금 없음, 의도적 보류)
- **오프라인 우선 아님:** 로그인 필수, Supabase 의존
- 1인 개발로 빠른 배포 사이클 유지, 웹·모바일 UI는 픽셀 단위로 동일하게 유지

### 타이머 기본값 근거

기본값(집중 25분 / 휴식 5분 / 4사이클)은 Francesco Cirillo의 포모도로 기법 원작을 따른다. 집중 시간 상한 120분은 울트라디안 리듬 연구(Peretz Lavie, 1986, 약 90분 주기)를 참고했고, 휴식 하한 0분은 휴식 없이 연속 사이클을 허용하기 위함이다. 사이클 상한 10회는 기본값의 2.5배로 하루 세션 한 회분을 충분히 커버한다.
